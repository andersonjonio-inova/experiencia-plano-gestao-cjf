# Experiência de aprendizagem: Plano de Gestão do CJF 2026–2028

Página estática e interativa para leitura estratégica do plano, com foco no conteúdo até as Considerações Finais. Material educacional não oficial, sintético e complementar ao documento institucional.

## Publicação

Acesse: https://andersonjonio-inova.github.io/experiencia-plano-gestao-cjf/

O site usa HTML, CSS e JavaScript, sem dependências externas, coleta de respostas ou armazenamento de progresso. Para atualização, edite os arquivos da página e publique na branch `main`, diretório raiz.
